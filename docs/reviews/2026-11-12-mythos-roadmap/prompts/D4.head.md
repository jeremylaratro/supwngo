# Dimension D4 — LLM integration: where to add hooks, and how to make them trustworthy (adversarial)

Your dimension: where should LLMs plug into supwngo so it becomes markedly better, and where would
they make it worse? Scope:
- **Find what exists.** Grep for current LLM usage (`anthropic`, `openai`, `ai`, `llm`, `prompt`,
  `model`) and assess it. The `ai` extra in `pyproject.toml` lists anthropic and openai.
- **Candidate hook points**, judged on value vs risk: triage and target classification; turning
  decompiler output into semantics (naming, types, struct recovery, input-format inference); bug
  hypothesis generation that is then *verified by tools* (data-flow, symbolic, fuzzing, crash);
  method selection across the overlapping engines; exploit-step synthesis with a tight
  propose → execute → observe loop (gdb, pwntools, the pipeline's executors); fuzzing harness and
  seed/dictionary generation; libc/version reasoning; report and walkthrough writing; an agent that
  drives supwngo's own commands as tools (CLI, Python API, or an MCP server).
- **Trust and determinism.** No hallucinated addresses/offsets reaching an exploit: every LLM claim
  must be checkable by a deterministic oracle. Provenance in outputs, caching, replay, evaluation with
  a falsifiable metric, cost/latency budgets, prompt-injection exposure from strings inside the target
  binary.
- **Offline-first.** The owner runs local open-weight models on DGX Spark nodes (vLLM,
  OpenAI-compatible API) and also has cloud models. Design a provider abstraction and model-routing
  policy (small local model for bulk, stronger model for hard steps), and say what model capability
  each hook actually needs.
- **Integration with the owner's LLM-agent platform.** Its agents mostly call command-line tools
  through a shell. Should supwngo expose a stable machine interface (JSON contracts, an MCP server,
  a Python API) so agents can use it as a toolbox? What would that interface look like?
Use `D4` as the ID prefix. For each hook, name the module/function where it would attach.
